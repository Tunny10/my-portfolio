รายละเอียดโปรเจกต์แชตบอต

🎯 ภาพรวมงาน: เป็นโปรเจกต์ในรายวิชาวิศวกรรมคอมพิวเตอร์ ที่เน้นฝึกฝนการดีไซน์หน้าจอซอฟต์แวร์และการแก้ปัญหา Layout

  • UI/UX Design: ออกแบบอินเตอร์เฟซและไอคอนโลโก้แชตบอตขึ้นเองทั้งหมดเพื่อความโดดเด่น
  • Responsive Layout: ใช้ระบบ Grid ของ Bootstrap ครอบคลุมการแสดงผลทั้งหน้าจอคอมพิวเตอร์และมือถือ
  • CSS แก้ไขจุดบั๊ก: ไล่เช็กและปรับแต่งระยะขอบ (Margin/Padding) และ Flexbox เพื่อแก้ปัญหาตำแหน่งกล่องข้อความเหลื่อมล้ำกัน
รายละเอียดเว็บไซต์พอร์ตโฟลิโอ

🎯 ภาพรวมงาน: หน้าเว็บประวัติส่วนตัวในรูปแบบ Single Page Application สไตล์ดาร์กธีมที่พัฒนาขึ้นเพื่อแนะนำตัวเองและทักษะต่อบุคคลทั่วไป

  • Full-Width Design: จัดระเบียบหน้าบล็อกสกิลและการศึกษาใหม่ให้อ่านง่าย กระชับ ไม่ทิ้งพื้นที่ว่างฝั่งซ้าย
  • Interactive Theme: ใช้พื้นหลังธีมห้วงอวกาศจับคู่กับการ์ดสไตล์กระจกฝ้า (Glassmorphism) เพิ่มความทันสมัย
  • Future Ready: เพิ่มส่วนโครงสร้างข้อมูลของทักษะภาษา JavaScript, C++ และส่วนเครื่องมือในการทำงานร่วมกับผู้อื่นไว้ครบครัน
Elden Ring Ending Tracker

🎯 ภาพรวมงาน: เว็บแอปพลิเคชันที่พัฒนาด้วย React สำหรับผู้เล่นเกม Elden Ring ใช้ติดตามขั้นตอนเควสไปสู่ฉากจบทั้ง 6 แบบของเกม

  • Dynamic Data Mapping: ออกแบบโครงสร้างข้อมูลแบบ JSON Schema เพื่อ Map เควสของแต่ละฉากจบแบบไดนามิก
  • Progress Tracking UI: สร้างระบบ Checklist พร้อมแถบแสดงความคืบหน้า (Progress Bar) แบบเรียลไทม์
